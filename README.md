# 🔥 CUPP Style Wordlist Generator

### Professional Password Profiling Tool

---

## 📋 Overview

CUPP Style Wordlist Generator is a professional password profiling tool that generates custom wordlists based on target information. It creates intelligent password combinations using personal details like name, birth date, pet names, hobbies, and more.

---

## ✨ Features

- **Personal Information Processing** - First name, last name, nickname, birth date
- **Smart Combinations** - Automatically generates variations and combinations
- **Date Formats** - Multiple date formats (DDMMYYYY, YYYY, DDMM, etc.)
- **Common Passwords** - Includes most common password patterns
- **Leet Speak** - Automatic leet language conversion (a→4, e→3, etc.)
- **Suffix Addition** - Adds common suffixes like 123, !, @, year
- **Progress Bar** - Real-time progress display during generation
- **Large Output** - Generates thousands of targeted passwords
